ADVANCE Student & Parent Portal demo

PREVIEW: Extract ZIP and open index.html in Chrome/Edge. Try Admin, Teacher and Parent tabs. Admin can add sample teachers/students; Teacher can record attendance, 1–5 stars, optional remarks, create tests and enter marks; Parent can select a sample child and view their information.

GITHUB + VERCEL (quick steps)
1. Visit https://github.com/new
2. Repository name: advance-student-parent-portal-demo. Choose Public or Private. Click Create repository.
3. Extract this ZIP. On the empty GitHub repo click Add file > Upload files. Drag index.html (and this README if you like) into the page.
4. Scroll down and click Commit changes.
5. Visit https://vercel.com and sign in with GitHub.
6. Click Add New > Project. Find advance-student-parent-portal-demo and click Import.
7. Configure Project: Root Directory ./ ; Framework Preset Other. Leave build/output settings at defaults/blank. Click Deploy.
8. When deployment succeeds, click Visit and copy the live URL to share with your client.

IMPORTANT: This is a front-end demonstration only. Role tabs are not real logins. There is no database, secure authentication, access control, persistent storage, parent-child linking, notification system, audit log or backups. Changes reset on refresh. All sample identities and data are fictional. Never put real children's personal information in this demo. A production build needs a secure backend/database, real role-based authentication, parent-child linking, protected APIs, audit history, backups and a privacy/consent process appropriate for minors.
